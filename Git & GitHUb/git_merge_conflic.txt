⚠️ Merge Conflict

Jab dono branches same line ko different tarah change kar dein:

git merge feature-practice

Git:

CONFLICT
Automatic merge failed
Conflict resolve:

File kholo → ye markers milenge:

<<<<<<< HEAD
MASTER VERSION
=======
FEATURE VERSION
>>>>>>> feature-practice

Jo version rakhna hai rakho, markers delete karo.

Phir:

git add "file.py"
git commit -m "Resolve merge conflict"
Formula yaad rakho:
merge
 ↓
CONFLICT
 ↓
file fix
 ↓
git add
 ↓
git commit
